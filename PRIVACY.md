# Privacy Policy

Effective date: 2026-09-18

GptBC is a local-first developer tool for GB Studio projects. The GptBC repository does not operate its own hosted user-account system, analytics service, advertising system, or telemetry backend.

## Data GptBC may access

When you ask GptBC to inspect a GB Studio project, it may read project files and assets that you provide or make available in the working environment. When you ask it to discover or import public resources, it may contact public upstream services such as GitHub and the official GB Studio plugin repository to retrieve metadata or files needed for that request.

## Data storage

Project audits, caches, backups, and provenance records created by the included command-line tools are stored locally in the selected project or user cache directories. GptBC does not transmit those local records to a GptBC-operated server because no GptBC-operated server is provided by this project.

Third-party platforms used with GptBC, including GitHub, Codex/ChatGPT, GB Studio resources, and other connected services, are governed by their own privacy policies and account settings.

## Third-party resources

GptBC can discover or import third-party plugins and assets. Those resources retain their own licenses, terms, and privacy practices. Review upstream terms before using third-party code or assets.

## Security

Do not commit secrets, access tokens, private keys, or credentials to this repository or to a GB Studio project. Security issues related to GptBC should be reported according to [SECURITY.md](SECURITY.md).

## Changes

This policy may be updated as GptBC adds features or external services. Material changes will be recorded in the repository history.

## Contact

Questions may be opened through the public issue tracker at https://github.com/scootieccc/GptBC/issues.
